

# 📓 Simple Journal (Notebook) App

**A lightweight command-line journal built with Python**



---

## 📖 Project Description

Simple Journal is a command-line application written in Python. It lets you write short journal entries, save them with the current date and time, and view, search or delete them later.

All entries are stored in a plain text file (`notebook.txt`), so **no database or extra installation is required**.

This project demonstrates core Python concepts: functions, loops, conditional statements, file handling and user input.

---

## ✨ Features

| Icon | Feature | Description |
|:---:|---|---|
| ➕ | **Add Entry** | Write a new entry and save it with date and time |
| 📄 | **View Entries** | Display all saved entries |
| 🔍 | **Search Entry** | Find entries by keyword (not case-sensitive) |
| 🗑️ | **Delete All** | Remove all entries after a yes/no confirmation |
| 🚪 | **Exit** | Close the program safely |
| ⚠️ | **Error Handling** | Clear messages for empty journal and invalid choices |

---

## 🛠️ Technologies Used

- 🐍 **Python 3**
- 🕒 **`datetime` module** (standard library) for date and time
- 📝 **Plain text file** (`notebook.txt`) for data storage
- 💻 **VS Code** and terminal for development and running

---

## 🚀 How to Run / Installation

**1. Install Python 3**
Download it from [python.org](https://www.python.org/downloads/) if it is not already installed.

**2. Download the project**
Copy the project folder to your computer.

**3. Open the folder**
Open it in VS Code or any terminal.

**4. Run the program**

```bash
python main.py
```

On Windows you can also use:

```bash
py main.py
```

**5. Use the menu**
Type a number from `1` to `5` and press Enter.
